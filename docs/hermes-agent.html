Hermes Agent (Nous Research) : ce qu'il permet

Un agent open source, auto-hébergeable, qui vit sur une machine (PC ou VPS Linux), garde une mémoire, apprend des skills et répond depuis la messagerie.

1. Par où on lui parle

  • Terminal (CLI)
  • Telegram, WhatsApp, Signal
  • Discord, Slack

Une seule « passerelle » (gateway) sert tous les canaux ; service systemd sous Linux.

2. Tâches planifiées

  • Planificateur cron intégré
  • Résultat envoyé sur la messagerie

Commandes dangereuses refusées par défaut : personne n'est là pour les valider.

3. Validation à distance

  • Commandes dangereuses soumises à ton accord
  • Refuser, une fois, pour la session ou toujours
  • Depuis Telegram, le Dashboard ou le terminal

La boucle de l'agent

Message→ Le modèle décide→ Appelle des outils→ Répond→ Retient
Le modèle (LLM)
Nous Portal (modèles Hermes), OpenRouter, OpenAI, ou tout endpoint compatible
Ici : DeepSeek, par son fournisseur intégré

Mémoire

  • MEMORY.md, USER.md
  • Recherche dans les sessions passées
  • Connecteurs externes (Honcho…)

Ici : seulement à ta demande (rappels désactivés).

Skills

  • Créées à partir de l'expérience
  • Corrigées à l'usage
  • Format agentskills.io, Skills Hub

« Self-improving » ; ici : seulement à ta demande.

4. Où il exécute

  • Local
  • Docker
  • SSH (une autre machine)
  • Modal, Singularity, Daytona…

Espaces de travail persistants ou jetables.

5. Outils branchés

  • Client MCP : n'importe quel serveur MCP
  • Commandes du terminal (donc tes CLI)

6. Sous-agents

  • Lancés en parallèle
  • Chacun sa conversation et son terminal

Ce que règle ce déploiement

Version épinglée de l'image ; Docker en lecture seule, par un proxy filtrant (jamais le socket) ; verrous : commandes dangereuses approuvées par toi, mémoire et skills seulement à ta demande ; Telegram limité à tes identifiants ; Dashboard derrière une connexion ; pare-feu du serveur. Tout s'installe et se met à jour par install.py.

En une phrase

Un assistant personnel qui tourne en permanence sur un serveur, joignable depuis le téléphone, qui se souvient de toi et apprend des procédures, et qui sait lancer des commandes sur des machines.
